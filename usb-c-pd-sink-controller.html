USB-C Power Delivery Sink Controller: Get 5V, 9V, 12V, 15V or 20V From Any PD Charger

By Hakimu Maganda | Category: Power Electronics | Published: 2026-11-08

Why You Need a USB-C PD Sink Controller

Tired of hunting for a 12V adapter that fits your project? A modern USB-C PD charger already has the power you need: 5V, 9V, 12V, 15V and 20V at up to 65W or more. The catch is that a PD charger outputs only 5V until your device asks for a higher voltage. Without a USB-C Power Delivery sink controller, your 12V fan, LED strip or ESP32 project never receives it.

In this guide you will build a programmable USB-C PD sink controller using the CH224K PD trigger chip and an ESP32. Press a button and the board requests a new voltage from the charger. An OLED shows the requested voltage, the measured voltage, current in mA, power in mW and a power-good status. It works as a compact USB-C bench power supply and is a solid base for DIY chargers, soldering irons, LED drivers and portable test rigs.

What you will learn:

  • How a USB PD sink controller negotiates voltage with a charger
  • How to wire a CH224K module to an ESP32 safely, including the 3.3V logic limit
  • How the CFG1, CFG2 and CFG3 pins select 5V, 9V, 12V, 15V and 20V
  • A safe-by-default design that boots at 9V and blocks 15V and 20V until you allow them
  • Production-ready Arduino C++ code with live power monitoring

Safety first: 15V and 20V can destroy loads that are rated for 5V or 12V only. Always check your load's maximum input voltage before enabling high-voltage profiles.

Why the 6.8k resistor matters: If CFG1 is left floating before the microcontroller boots, the CH224K can request 20V. The 6.8k resistor to GND forces a safe 9V request at startup, and the firmware starts in the matching 9V profile so no re-negotiation glitch occurs.

Module warning: Many CH224K boards have solder jumpers or onboard pull-up and pull-down resistors on the CFG lines. Open or remove these before wiring the ESP32. With the ESP32 disconnected and only the 6.8k resistor fitted, confirm with a multimeter that the module outputs about 9V before connecting any load.

Clean, Production-Ready Code (Arduino C++ for ESP32)

Libraries to install (Arduino IDE, Library Manager): Adafruit SSD1306, Adafruit GFX Library and Adafruit INA219. Also install Adafruit BusIO if prompted.

Board package: esp32 by Espressif Systems. Select the board "ESP32 Dev Module".

/*
  USB-C Power Delivery Sink Controller
  Tech Circuit Guide - techcircuitguide.com
  Author: Hakimu Maganda
  Hardware: ESP32 + CH224K PD module + INA219 + SSD1306 OLED

  Behavior:
  - Boots in the 9V profile (matches the 6.8k resistor on CFG1).
  - Button press cycles through allowed voltage profiles.
  - 15V and 20V are BLOCKED unless ALLOW_HIGH_VOLTAGE is set to true.
  - OLED shows target voltage, measured voltage, current, power and status.
*/

#include <Arduino.h>
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#include <Adafruit_INA219.h>

// ---------------- Pin configuration ----------------
#define I2C_SDA_PIN  21
#define I2C_SCL_PIN  22
#define PIN_CFG1     25   // CH224K CFG1
#define PIN_CFG2     26   // CH224K CFG2
#define PIN_CFG3     27   // CH224K CFG3
#define PIN_PG       32   // CH224K PG (active LOW = power good)
#define PIN_BTN      33   // Push button to GND

// ---------------- Display configuration ----------------
#define SCREEN_WIDTH  128
#define SCREEN_HEIGHT 64
#define OLED_ADDR     0x3C

// ---------------- Safety settings ----------------
// Set to true ONLY if your load is rated for 15V and 20V.
const bool ALLOW_HIGH_VOLTAGE = false;

// Set to false if your module does not expose the PG pin.
const bool USE_PG_PIN = true;

// ---------------- PD profile table ----------------
// Matches the CH224K level configuration truth table.
struct PdProfile {
  uint8_t volts;
  uint8_t cfg1;
  uint8_t cfg2;
  uint8_t cfg3;
};

const PdProfile PROFILES[] = {
  {  5, HIGH, LOW,  LOW  },  // CFG1=1 gives 5V
  {  9, LOW,  LOW,  LOW  },  // CFG1=0, CFG2=0, CFG3=0 gives 9V
  { 12, LOW,  LOW,  HIGH },  // CFG1=0, CFG2=0, CFG3=1 gives 12V
  { 15, LOW,  HIGH, HIGH },  // CFG1=0, CFG2=1, CFG3=1 gives 15V
  { 20, LOW,  HIGH, LOW  }   // CFG1=0, CFG2=1, CFG3=0 gives 20V
};

const uint8_t PROFILE_COUNT   = sizeof(PROFILES) / sizeof(PROFILES[0]);
const uint8_t DEFAULT_PROFILE = 1;   // 9V, matches hardware default

// ---------------- Globals ----------------
Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1);
Adafruit_INA219  ina219;

uint8_t       currentIdx = DEFAULT_PROFILE;
unsigned long changedAt  = 0;
unsigned long lastDraw   = 0;
unsigned long lastPress  = 0;
bool          wasDown    = false;

// ---------------- Apply a PD profile ----------------
// CFG2 and CFG3 are written first, CFG1 last, to reduce transient states.
void applyProfile(uint8_t idx) {
  const PdProfile &p = PROFILES[idx];
  digitalWrite(PIN_CFG2, p.cfg2);
  digitalWrite(PIN_CFG3, p.cfg3);
  digitalWrite(PIN_CFG1, p.cfg1);
  currentIdx = idx;
  changedAt  = millis();
  Serial.printf("Requested profile: %uV\n", p.volts);
}

// ---------------- Find next allowed profile ----------------
uint8_t nextIndex(uint8_t idx) {
  for (uint8_t i = 1; i <= PROFILE_COUNT; i++) {
    uint8_t n = (idx + i) % PROFILE_COUNT;
    if (ALLOW_HIGH_VOLTAGE || PROFILES[n].volts <= 12) {
      return n;
    }
  }
  return idx;
}

// ---------------- Status evaluation ----------------
const char* statusText(float busV) {
  uint8_t target = PROFILES[currentIdx].volts;

  if (millis() - changedAt < 1500) return "NEGOTIATING";

  bool vOk    = fabsf(busV - (float)target) <= ((float)target * 0.15f);
  bool pgGood = USE_PG_PIN ? (digitalRead(PIN_PG) == LOW) : true;

  if (pgGood && vOk) return "OK";
  if (!vOk)          return "V MISMATCH";
  return "PG FAULT";
}

// ---------------- Button handling ----------------
void handleButton() {
  bool down = (digitalRead(PIN_BTN) == LOW);
  if (down && !wasDown && (millis() - lastPress > 50)) {
    lastPress = millis();
    applyProfile(nextIndex(currentIdx));
  }
  wasDown = down;
}

// ---------------- OLED update ----------------
void updateDisplay() {
  float busV  = ina219.getBusVoltage_V();
  float curmA = ina219.getCurrent_mA();
  float powmW = ina219.getPower_mW();
  const char* st = statusText(busV);

  display.clearDisplay();
  display.setTextSize(1);
  display.setTextColor(SSD1306_WHITE);

  display.setCursor(0, 0);
  display.print("PD Target: ");
  display.print(PROFILES[currentIdx].volts);
  display.println("V");

  display.setCursor(0, 14);
  display.print("Measured : ");
  display.print(busV, 2);
  display.println("V");

  display.setCursor(0, 26);
  display.print("Current  : ");
  display.print(curmA, 0);
  display.println("mA");

  display.setCursor(0, 38);
  display.print("Power    : ");
  display.print(powmW, 0);
  display.println("mW");

  display.setCursor(0, 52);
  display.print("Status: ");
  display.print(st);

  display.display();

  Serial.printf("Target=%uV Bus=%.2fV I=%.0fmA P=%.0fmW Status=%s\n",
                PROFILES[currentIdx].volts, busV, curmA, powmW, st);
}

// ---------------- Setup ----------------
void setup() {
  Serial.begin(115200);
  delay(200);

  // CFG pins start as outputs at the 9V profile (all LOW),
  // matching the hardware default set by the 6.8k resistor.
  pinMode(PIN_CFG1, OUTPUT);
  pinMode(PIN_CFG2, OUTPUT);
  pinMode(PIN_CFG3, OUTPUT);
  pinMode(PIN_PG,   INPUT_PULLUP);
  pinMode(PIN_BTN,  INPUT_PULLUP);

  applyProfile(DEFAULT_PROFILE);

  Wire.begin(I2C_SDA_PIN, I2C_SCL_PIN);

  if (!display.begin(SSD1306_SWITCHCAPVCC, OLED_ADDR)) {
    Serial.println("ERROR: SSD1306 not found. Check wiring and address 0x3C.");
    for (;;) { delay(1000); }
  }

  if (!ina219.begin()) {
    Serial.println("ERROR: INA219 not found. Check wiring and address 0x40.");
    display.clearDisplay();
    display.setTextSize(1);
    display.setTextColor(SSD1306_WHITE);
    display.setCursor(0, 0);
    display.println("INA219 NOT FOUND");
    display.println("Check I2C wiring");
    display.display();
    for (;;) { delay(1000); }
  }

  // 32V range, 2A max calibration (suits 0.1 ohm shunt modules)
  ina219.setCalibration_32V_2A();

  Serial.println("USB-C PD Sink Controller ready.");
}

// ---------------- Main loop ----------------
void loop() {
  handleButton();

  if (millis() - lastDraw >= 250) {
    lastDraw = millis();
    updateDisplay();
  }
}

Step-By-Step Implementation Guide

Step 1: Prepare the CH224K Module

  • Inspect your module for solder jumpers or resistors on CFG1, CFG2 and CFG3. Open or remove any that tie those pins to fixed levels.
  • Identify the VOUT (+), GND, CFG1, CFG2, CFG3 and PG pads. Pad labels vary between sellers, so check the silkscreen.

Step 2: Set the Buck Converter Before Connecting the ESP32

  • Feed the buck converter with 9V to 12V from a bench supply or the PD module.
  • Turn the trimmer until the output reads exactly 5.0V on a multimeter.
  • Only then connect it to the ESP32 VIN pin.

Step 3: Fit the Safe-Default Resistor

  • Solder the 6.8k resistor between CFG1 and GND, with the ESP32 and load disconnected.

Step 4: Bench-Test the Module Alone

  • Plug in the PD charger with only the CH224K, the 6.8k resistor and a multimeter on VOUT.
  • Confirm about 9V. If you read 5V or 20V, recheck for leftover pull-ups or jumpers.

Step 5: Wire the ESP32, INA219 and OLED

  • Follow the pin table: SDA to GPIO21 and SCL to GPIO22 for both the INA219 and the OLED.
  • Power both from the ESP32 3V3 pin.
  • Connect CFG1, CFG2 and CFG3 to GPIO25, GPIO26 and GPIO27, and PG to GPIO32.
  • Connect the button between GPIO33 and GND.
  • Tie all grounds together.

Step 6: Upload the Code

  • Install the libraries listed above and the ESP32 board package.
  • Open the sketch, select ESP32 Dev Module and the correct COM port.
  • Click Upload. If it stalls at "Connecting...", hold the BOOT button on the ESP32.
  • Open the Serial Monitor at 115200 baud to see live readings.

Step 7: Test With a Safe Load

  • Connect a small resistor load or a 12V-tolerant device.
  • Press the button to cycle 9V, 12V and 5V, and confirm the Measured value tracks the target.
  • Enable 15V and 20V only after setting ALLOW_HIGH_VOLTAGE to true and confirming your load rating.

Troubleshooting and FAQs

Wiring and Hardware Problems

Why does my CH224K only output 5V?
Common causes are a charger that does not offer the requested voltage profile, a low-quality cable, or CFG1 being held HIGH by a leftover jumper or pull-up. Try a different PD charger and confirm its label lists the voltage you want.

Why did my board output 20V at startup?
A floating CFG1 can lead to a 20V request. Fit the 6.8k resistor from CFG1 to GND for a safe 9V default before the microcontroller boots.

Can I use an Arduino Uno or Nano with the CH224K?
Not directly. CFG2 and CFG3 are limited to 3.7V on the CH224K, so use a 3.3V microcontroller such as the ESP32 or Pico, or add level shifting.

My OLED stays blank. What should I check?
Run an I2C scanner. The OLED is normally at 0x3C and the INA219 at 0x40. Check that SDA and SCL are not swapped and that both modules share GND with the ESP32.

The ESP32 resets when I change voltage.
The buck converter input is probably dipping during the transition. Add a 100uF to 470uF capacitor on the buck input and use short, thick wires on the PD rail.

The INA219 shows 0 mA or negative current.
Check that current flows from VIN+ to VIN-. Swapped terminals give negative readings.

Compilation and Upload Errors

Error: Adafruit_INA219.h: No such file or directory
Install "Adafruit INA219" from the Library Manager, along with Adafruit BusIO.

Error: SSD1306 allocation failed, or display not found
Check the I2C address (0x3C or 0x3D) and the wiring, and make sure you selected an ESP32 board rather than an Arduino board.

Upload stuck on "Connecting........"
Hold the BOOT button while uploading, use a data-capable USB cable, and install the CP210x or CH340 driver for your board.

Long-Tail Questions

How do I get 12V from a USB-C charger?
Use a PD trigger or sink chip such as the CH224K, set CFG1, CFG2 and CFG3 to 0, 0 and 1, and use a charger that supports 12V PD.

Does the CH224K support PPS or adjustable voltage?
The CH224K selects fixed PD voltages (5V, 9V, 12V, 15V and 20V). Variants such as the CH224Q and CH224A add I2C control. Check the datasheet for the exact part you buy.

What is the maximum current?
It depends on your charger and cable. Standard cables carry 3A, and 5A needs a suitably rated cable and charger. This build is limited to about 3.2A by the INA219 shunt, so use a different current sensor for heavier loads.

Can I power a 12V LED strip directly?
Yes, if the strip is rated for 12V and within your charger's wattage. Test at 9V first and watch the current on the OLED.
