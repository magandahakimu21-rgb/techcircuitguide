The catch is that a PD charger outputs only 5V until your device *asks* for a higher voltage. Without a **USB-C Power Delivery sink controller**, your 12V fan, LED strip or ESP32 project never gets it. In this guide you will build a **programmable USB-C PD sink controller** using the **CH224K** PD trigger chip and an **ESP32**. Press a button and the board requests a new voltage from the charger. An OLED shows the requested voltage, the measured voltage, current (mA) and power (mW), plus a power-good status. It is a compact **USB-C bench power supply** you can build for a few dollars' worth of parts, and a solid base for DIY chargers, soldering irons, LED drivers and portable test rigs. **What you will learn:** - How a USB PD sink controller negotiates voltage with a charger - How to wire a CH224K module to an ESP32 safely (including the 3.3V logic limit) - How the CFG1/CFG2/CFG3 pins select 5V, 9V, 12V, 15V and 20V - A safe-by-default design that boots at 9V and blocks 15V/20V until you allow it - Production-ready Arduino C++ code with live power monitoring > **Safety first:** 15V and 20V can destroy 5V or 12V-only loads. The 6.8k resistor to GND forces a safe 9V request at startup, and the firmware starts in the matching 9V profile so no re-negotiation glitch occurs. **Module warning:** Many CH224K boards have solder jumpers or onboard pull-up/pull-down resistors on the CFG lines. Open or remove these before wiring the ESP32. Test with a multimeter that the module outputs 9V with the ESP32 disconnected and only the 6.8k resistor fitted, **before** connecting any load. --- ## Schematic Wiring Diagram ```mermaid flowchart LR CHG["USB-C PD Charger 45W+"] -->|"USB-C cable"| MOD["CH224K PD Sink Module"] MOD -->|"VOUT 5V to 20V"| INA["INA219 VIN+"] MOD -->|"VOUT 5V to 20V"| BUCK["Buck 5.0V IN+"] INA -->|"VIN-"| LOAD["Load (+) Terminal"] BUCK -->|"5.0V"| ESP["ESP32 VIN"] ESP -->|"GPIO25"| CFG1["CH224K CFG1"] ESP -->|"GPIO26"| CFG2["CH224K CFG2"] ESP -->|"GPIO27"| CFG3["CH224K CFG3"] MOD -->|"PG (active LOW)"| PG["ESP32 GPIO32"] ESP -->|"3V3"| I2C["INA219 + OLED VCC"] ESP -->|"GPIO21 SDA / GPIO22 SCL"| BUS["INA219 + SSD1306 I2C"] BTN["Push Button"] -->|"GPIO33 to GND"| ESP R1["6.8k resistor"] -->|"CFG1 to GND"| CFG1 GND(("Common GND")) --- MOD GND --- ESP GND --- BUCK GND --- LOAD ``` **ASCII power-rail view:** ```text PD Charger --USB-C--> [CH224K] ---VOUT(5-20V)---+---> [INA219 VIN+ ... Select board "ESP32 Dev Module". ```cpp /* USB-C Power Delivery Sink Controller Tech Circuit Guide - techcircuitguide.com Author: Hakimu Maganda Hardware: ESP32 + CH224K PD module + INA219 + SSD1306 OLED Behavior: - Boots in the 9V profile (matches the 6.8k resistor on CFG1). - Button press cycles through allowed voltage profiles. - 15V and 20V are BLOCKED unless ALLOW_HIGH_VOLTAGE is set to true. - OLED shows target voltage, measured voltage, current, power and status. */ #include #include #include #include #include // ---------------- Pin configuration ---------------- #define I2C_SDA_PIN 21 #define I2C_SCL_PIN 22 #define PIN_CFG1 25 // CH224K CFG1 #define PIN_CFG2 26 // CH224K CFG2 #define PIN_CFG3 27 // CH224K CFG3 #define PIN_PG 32 // CH224K PG (active LOW = power good) #define PIN_BTN 33 // Push button to GND // ---------------- Display configuration ---------------- #define SCREEN_WIDTH 128 #define SCREEN_HEIGHT 64 #define OLED_ADDR 0x3C // ---------------- Safety settings ---------------- // Set to true ONLY if your load is rated for 15V and 20V. const bool ALLOW_HIGH_VOLTAGE = false; // Set to false if your module does not expose the PG pin. const bool USE_PG_PIN = true; // ---------------- PD profile table ---------------- // Matches the CH224K level configuration truth table. struct PdProfile { uint8_t volts; uint8_t cfg1; uint8_t cfg2; uint8_t cfg3; }; const PdProfile PROFILES[] = { { 5, HIGH, LOW, LOW }, // CFG1=1 -> 5V { 9, LOW, LOW, LOW }, // CFG1=0 0 0 -> 9V { 12, LOW, LOW, HIGH }, // CFG1=0 0 1 -> 12V { 15, LOW, HIGH, HIGH }, // CFG1=0 1 1 -> 15V { 20, LOW, HIGH, LOW } // CFG1=0 1 0 -> 20V }; const uint8_t PROFILE_COUNT = sizeof(PROFILES) / sizeof(PROFILES[0]); const uint8_t DEFAULT_PROFILE = 1; // 9V, matches hardware default // ---------------- Globals ---------------- Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1); Adafruit_INA219 ina219; uint8_t currentIdx = DEFAULT_PROFILE; unsigned long changedAt = 0; unsigned long lastDraw = 0; unsigned long lastPress = 0; bool wasDown = false; // ---------------- Apply a PD profile ---------------- // CFG2/CFG3 are written first, CFG1 last, to reduce transient states. void applyProfile(uint8_t idx) { const PdProfile &p = PROFILES[idx]; digitalWrite(PIN_CFG2, p.cfg2); digitalWrite(PIN_CFG3, p.cfg3); digitalWrite(PIN_CFG1, p.cfg1); currentIdx = idx; changedAt = millis(); Serial.printf("Requested profile: %uV\n", p.volts); } // ---------------- Find next allowed profile ---------------- uint8_t nextIndex(uint8_t idx) { for (uint8_t i = 1; i <= PROFILE_COUNT; i++) { uint8_t n = (idx + i) % PROFILE_COUNT; if (ALLOW_HIGH_VOLTAGE || PROFILES[n].volts <= 12) { return n; } } return idx; } // ---------------- Status evaluation ---------------- const char* statusText(float busV) { uint8_t target = PROFILES[currentIdx].volts; if (millis() - changedAt < 1500) return "NEGOTIATING"; bool vOk = fabsf(busV - (float)target) <= ((float)target * 0.15f); bool pgGood = USE_PG_PIN ? (digitalRead(PIN_PG) == LOW) : true; if (pgGood && vOk) return "OK"; if (!vOk) return "V MISMATCH"; return "PG FAULT"; } // ---------------- Button handling ---------------- void handleButton() { bool down = (digitalRead(PIN_BTN) == LOW); if (down && !wasDown && (millis() - lastPress > 50)) { lastPress = millis(); applyProfile(nextIndex(currentIdx)); } wasDown = down; } // ---------------- OLED update ---------------- void updateDisplay() { float busV = ina219.getBusVoltage_V(); float curmA = ina219.getCurrent_mA(); float powmW = ina219.getPower_mW(); const char* st = statusText(busV); display.clearDisplay(); display.setTextSize(1); display.setTextColor(SSD1306_WHITE); display.setCursor(0, 0); display.print("PD Target: "); display.print(PROFILES[currentIdx].volts); display.println("V"); display.setCursor(0, 14); display.print("Measured : "); display.print(busV, 2); display.println("V"); display.setCursor(0, 26); display.print("Current : "); display.print(curmA, 0); display.println("mA"); display.setCursor(0, 38); display.print("Power : "); display.print(powmW, 0); display.println("mW"); display.setCursor(0, 52); display.print("Status: "); display.print(st); display.display(); Serial.printf("Target=%uV Bus=%.2fV I=%.0fmA P=%.0fmW Status=%s\n", PROFILES[currentIdx].volts, busV, curmA, powmW, st); } // ---------------- Setup ---------------- void setup() { Serial.begin(115200); delay(200); // CFG pins start as outputs at the 9V profile (all LOW), // matching the hardware default set by the 6.8k resistor. pinMode(PIN_CFG1, OUTPUT); pinMode(PIN_CFG2, OUTPUT); pinMode(PIN_CFG3, OUTPUT); pinMode(PIN_PG, INPUT_PULLUP); pinMode(PIN_BTN, INPUT_PULLUP); applyProfile(DEFAULT_PROFILE); Wire.begin(I2C_SDA_PIN, I2C_SCL_PIN); if (!display.begin(SSD1306_SWITCHCAPVCC, OLED_ADDR)) { Serial.println("ERROR: SSD1306 not found. Check wiring and address 0x3C."); for (;;) { delay(1000); } } if (!ina219.begin()) { Serial.println("ERROR: INA219 not found. Check wiring and address 0x40."); display.clearDisplay(); display.setTextSize(1); display.setTextColor(SSD1306_WHITE); display.setCursor(0, 0); display.println("INA219 NOT FOUND"); display.println("Check I2C wiring"); display.display(); for (;;) { delay(1000); } } // 32V range, 2A max calibration (suits 0.1 ohm shunt modules) ina219.setCalibration_32V_2A(); Serial.println("USB-C PD Sink Controller ready."); } // ---------------- Main loop ---------------- void loop() { handleButton(); if (millis() - lastDraw >= 250) { lastDraw = millis(); updateDisplay(); } } ``` --- ## Step-By-Step Implementation Guide ### Step 1: Prepare the CH224K module 1. Inspect your module for solder jumpers or resistors on CFG1, CFG2 and CFG3. Open or remove any that tie those pins to fixed levels. 2. Identify the VOUT (+), GND, CFG1, CFG2, CFG3 and PG pads. Pad labels vary between sellers, so check the silkscreen. ### Step 2: Set the buck converter BEFORE connecting the ESP32 1. Feed the buck converter with 9V to 12V from a bench supply or the PD module. 2. Turn the trimmer until the output reads exactly 5.0V on a multimeter. 3. Only then connect it to the ESP32 VIN pin. ### Step 3: Fit the safe-default resistor Solder the 6.8k resistor between CFG1 and GND, with ESP32 and load disconnected. ### Step 4: Bench-test the module alone 1. Plug in the PD charger with only the CH224K, the 6.8k resistor and a multimeter on VOUT. 2. Confirm about 9V. If you read 5V or 20V, recheck for leftover pull-ups or jumpers. ### Step 5: Wire the ESP32, INA219 and OLED 1. Follow the pin table: SDA to GPIO21, SCL to GPIO22 for both the INA219 and OLED. 2. Power both from the ESP32 3V3 pin. 3. Connect CFG1/CFG2/CFG3 to GPIO25/26/27 and PG to GPIO32. 4. Connect the button between GPIO33 and GND. 5. Tie **all grounds together**. ### Step 6: Upload the code 1. Install the libraries listed above and the ESP32 board package. 2. Open the sketch, select **ESP32 Dev Module** and the correct COM port. 3. Click **Upload**. If it stalls at "Connecting...", hold the BOOT button on the ESP32. 4. Open Serial Monitor at 115200 baud to see live readings. ### Step 7: Test with a safe load 1. Connect a small resistor load or a 12V-tolerant device. 2. Press the button to cycle 5V > 9V > 12V and confirm the "Measured" value tracks the target. 3. Enable 15V/20V only after setting `ALLOW_HIGH_VOLTAGE = true` and confirming your load rating. **Next step:** Learn more about the sensor in [ESP32 + INA219 Power Monitor Guide](/guides/esp32-ina219-power-monitor.html), and set up your regulator with [LM2596 Buck Converter Setup Guide](/guides/lm2596-buck-converter-setup.html). --- ## Troubleshooting & FAQs ### Wiring and hardware problems **Why does my CH224K only output 5V?** Common causes: the charger does not offer the requested voltage profile, the cable is low quality, CFG1 is being held HIGH (check your jumpers and pull-ups), or the module needs a different USB-C port. Try a different PD charger, and confirm the charger label lists the voltage you want. **Why did my board output 20V at startup?** A floating CFG1 can lead to a 20V request. Fit the 6.8k resistor from CFG1 to GND for a safe 9V default before the MCU boots. **Can I use an Arduino Uno or Nano with the CH224K?** Not directly. CFG2 and CFG3 are limited to 3.7V on the CH224K, so use a 3.3V MCU like the ESP32 or Pico, or add level shifting. **My OLED stays blank.** Run an I2C scanner. The OLED is normally at 0x3C and the INA219 at 0x40. Check SDA/SCL are not swapped and that both modules share GND with the ESP32. **The ESP32 resets when I change voltage.** The buck converter input is dipping during the transition. Add a 100 uF to 470 uF capacitor on the buck input, and use a short, thick wire for the PD rail. **The INA219 shows 0 mA or negative current.** Check the current flows from VIN+ to VIN-. Swapped terminals give negative readings. ### Compilation and upload errors **`fatal error: Adafruit_INA219.h: No such file or directory`** Install "Adafruit INA219" from Library Manager, along with Adafruit BusIO. **`SSD1306 allocation failed` / display not found** Check the I2C address (0x3C or 0x3D), wiring, and that you selected an ESP32 board (not an Arduino board). **Upload stuck on "Connecting........"** Hold the BOOT button while uploading, use a data-capable USB cable, and install the CP210x or CH340 driver for your board. ### Long-tail questions **How do I get 12V from a USB-C charger?** Use a PD trigger/sink chip such as the CH224K, set CFG1/CFG2/CFG3 to 0, 0, 1, and use a charger that supports 12V PD. **Does the CH224K support PPS or adjustable voltage?** The CH224K selects fixed PD voltages (5V, 9V, 12V, 15V, 20V). Variants such as the CH224Q/CH224A add I2C control. Check the datasheet for the exact part you buy. **What is the maximum current?** It depends on your charger and cable (3A with a standard cable, 5A needs a suitably rated cable and charger). This build is limited to about 3.2A by the INA219 shunt, so use a different current sensor for heavier loads. **Can I power a 12V LED strip directly?** Yes, if the strip is rated for 12V and within your charger's wattage. Always test at 9V first and watch the current on the OLED. --- ## Monetization & Engagement Hooks > **Affiliate disclosure:** Some links below may earn Tech Circuit Guide a small commission at no extra cost to you.
