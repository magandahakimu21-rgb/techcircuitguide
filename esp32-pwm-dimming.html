Design Equations & Calculations

Proper current-limiting selection prevents overcurrent conditions on the ESP32 GPIO pin (max continuous rating: $40\text{mA}$, recommended: $20\text{mA}$).

1. Current-Limiting Resistor Calculation (Ohm's Law):

$$R = \frac{V_{cc} - V_f}{I_f}$$

Where:

  • $V_{cc} = 3.3\text{V}$ (ESP32 GPIO High Output Voltage)
  • $V_f = 2.0\text{V}$ (Forward voltage drop of standard Red LED)
  • $I_f = 6\text{mA} = 0.006\text{A}$ (Target drive current for safe extended operation)
$$R = \frac{3.3\text{V} - 2.0\text{V}}{0.006\text{A}} = \frac{1.3\text{V}}{0.006\text{A}} \approx 216.67\,\Omega$$

Standard Value Selection: We choose the standard $220\,\Omega$ resistor, yielding $I_f \approx 5.9\text{mA}$.

2. Resistor Power Dissipation:

$$P_R = I_f^2 \cdot R = (0.0059\text{A})^2 \cdot 220\,\Omega \approx 0.0076\text{W} \quad (7.6\text{mW})$$

Since $7.6\text{mW} \ll 250\text{mW}$ ($1/4\text{W}$ power rating), a standard axial resistor operates exceptionally cool.

Layout Considerations & Thermal Guidance

PCB / Breadboard Trace Guidance: Keep the signal trace from GPIO 18 to the current-limiting resistor under $50\text{mm}$ to minimize parasitic inductance and capacitive coupling. High PWM frequencies ($5\text{kHz}$) generate fast edge transitions that can produce mild high-frequency EMI if long unshielded jumper wires are used.

Thermal Dissipation: The ESP32's internal low-dropout regulator (LDO) handles power conversion from USB (5V) to 3.3V. Driving a single LED at $\approx 6\text{mA}$ introduces negligible thermal load ($P_{thermal} = (5\text{V} - 3.3\text{V}) \times 6\text{mA} = 10.2\text{mW}$). No thermal vias or passive heatsinks are required for this setup.

Source Code (Arduino Core v3.x API)

Espressif updated the LEDC (PWM) driver in Arduino Core v3.x. The legacy ledcSetup() and ledcAttachPin() functions have been consolidated into a single simplified API: ledcAttach().

// ESP32 PWM LED Fading using Arduino Core v3.x Syntax
// Target Board: ESP32 Dev Module

const int ledPin = 18;      // GPIO Pin connected to LED
const int freq = 5000;       // PWM Frequency: 5 kHz
const int resolution = 8;  // 8-Bit Resolution (Values 0 - 255)

void setup() {
  // v3.x API: Attaches pin, frequency, and resolution in one call
  ledcAttach(ledPin, freq, resolution);
}

void loop() {
  // Fade in from minimum to maximum brightness
  for (int dutyCycle = 0; dutyCycle <= 255; dutyCycle += 5) {
    ledcWrite(ledPin, dutyCycle);
    delay(15);
  }

  // Fade out from maximum to minimum brightness
  for (int dutyCycle = 255; dutyCycle >= 0; dutyCycle -= 5) {
    ledcWrite(ledPin, dutyCycle);
    delay(15);
  }
}
