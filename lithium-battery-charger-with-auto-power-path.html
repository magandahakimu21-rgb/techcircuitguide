Lithium Battery Charger with Auto Power-Path: Run Your Project While It Charges

By Hakimu Maganda | Category: Power Electronics | Published: 2026-11-08

Why You Need a Power-Path Lithium Charger

Does your ESP32 project reset, overheat the battery, or never finish charging when you plug in the charger? That is the classic problem with a basic TP4056 board. It charges the battery but has no idea a load is attached, so the load steals charge current, the charge cycle never terminates correctly, and the battery sits at full voltage under constant stress.

A lithium battery charger with auto power-path fixes this at the hardware level. When external power is present, the load runs from the input and the leftover current charges the battery. When you unplug the input, the load switches over to the battery with no reset. This is the same power-path behavior used in phones, power banks and solar sensor nodes.

In this guide you will build a complete load-sharing Li-ion charger around the BQ24074 power-path charger, and add an ESP32 that reads battery voltage, detects external power, shows charging status on an OLED, and can optionally stop charging at about 80 percent to extend battery life.

What you will learn:

  • How power-path charging works and why it beats a TP4056 for powered projects
  • How to wire the BQ24074 charger board to an ESP32 safely, including protecting 3.3V GPIO pins
  • How to read battery voltage, power-good and charge status in firmware
  • How to use the CE pin to hold the charge level for longer battery life
  • Production-ready Arduino C++ code with low-battery protection

Safety first: Lithium cells can catch fire if charged incorrectly. Use only a single-cell 3.7V/4.2V Li-ion or LiPo battery with a built-in protection circuit, check polarity twice, and never leave a new build charging unattended.

Hardware Wiring Breakdown Table

How Power-Path Works in This Build

  • Input present: The OUT pin provides a regulated rail of up to 4.4V to your load, and any spare current charges the battery.
  • Input removed: OUT follows the battery voltage (roughly 3.0V to 4.2V) with no interruption.
  • Heavy load: If the load needs more than the input can give, the battery supplements it.

Because OUT is only 3.0V to 4.4V, this build adds a 5V boost module so the ESP32 DevKit's own regulator has a stable supply.

Why the diodes matter: PGOOD and CHG are open-drain outputs, and on many breakouts they drive an indicator LED that is fed from the charger's own supply. When released, those pins can sit at the OUT voltage (up to 4.4V), which is higher than the ESP32 can safely accept on a GPIO. A small diode with a pull-up to 3.3V solves this: the diode conducts only when the charger pulls the pin low, and blocks the higher voltage otherwise. It works no matter which rail your board's LED uses.

Clean, Production-Ready Code (Arduino C++ for ESP32)

Libraries to install (Arduino IDE, Library Manager): Adafruit SSD1306 and Adafruit GFX Library. Also install Adafruit BusIO if prompted.

Board package: esp32 by Espressif Systems (use a recent version, since the sketch uses analogReadMilliVolts). Select the board "ESP32 Dev Module".

/*
  Lithium Battery Charger with Auto Power-Path - ESP32 Monitor
  Tech Circuit Guide - techcircuitguide.com
  Author: Hakimu Maganda
  Hardware: ESP32 + BQ24074 power-path charger board + SSD1306 OLED

  What it does:
  - Detects external power (PGOOD, active LOW)
  - Detects charging (CHG, active LOW; flashing means a charge timer fault)
  - Measures battery voltage through a 100k/100k divider on GPIO34
  - Estimates battery percentage (approximate)
  - Optionally pauses charging at CHARGE_STOP_V using the CE pin
  - Deep-sleeps if the battery is nearly empty and no external power is present
*/

#include <Arduino.h>
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#include "esp_sleep.h"

// ---------------- Pin configuration ----------------
#define I2C_SDA_PIN   21
#define I2C_SCL_PIN   22
#define PIN_VBAT_ADC  34   // Battery divider midpoint (input only, ADC1)
#define PIN_PGOOD     32   // Charger PGOOD via diode, LOW = valid input power
#define PIN_CHG       33   // Charger CHG via diode, LOW = charging
#define PIN_CE        25   // Charger CE, LOW = charge enabled, HIGH = charge paused

// ---------------- Display configuration ----------------
#define SCREEN_WIDTH  128
#define SCREEN_HEIGHT 64
#define OLED_ADDR     0x3C

// ---------------- Settings ----------------
const float DIVIDER_RATIO = 2.0f;    // 100k + 100k divider
const float VBAT_CAL      = 1.000f;  // Calibration: multimeter volts / displayed volts

// Battery-life option: pause charging near 80 percent to reduce cell stress.
// Voltage is read while charging, so it reads slightly above the resting voltage.
const bool  LIMIT_CHARGE     = false;
const float CHARGE_STOP_V    = 4.00f;
const float CHARGE_RESUME_V  = 3.90f;

// Low-battery handling (the cell's own protection circuit is the real safety net)
const float LOW_BATT_WARN_V  = 3.45f;
const float CUTOFF_V         = 3.30f;
const uint64_t SLEEP_US      = 60ULL * 1000000ULL;  // Re-check every 60 seconds

const uint8_t ADC_SAMPLES    = 32;

// ---------------- Approximate Li-ion voltage to percent curve ----------------
struct CurvePoint {
  float volts;
  float percent;
};

const CurvePoint CURVE[] = {
  { 3.30f,   0.0f },
  { 3.50f,   5.0f },
  { 3.65f,  20.0f },
  { 3.75f,  40.0f },
  { 3.85f,  60.0f },
  { 3.95f,  75.0f },
  { 4.05f,  90.0f },
  { 4.20f, 100.0f }
};

const uint8_t CURVE_COUNT = sizeof(CURVE) / sizeof(CURVE[0]);

// ---------------- Globals ----------------
Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1);
bool oledOk = false;

bool          chargeEnabled = true;
bool          lastChg       = false;
uint8_t       chgToggles    = 0;
bool          timerFault    = false;
unsigned long windowStart   = 0;
unsigned long lastSample    = 0;
unsigned long lastUpdate    = 0;
uint8_t       lowCount      = 0;

// ---------------- Battery percentage estimate ----------------
float percentFromVoltage(float v) {
  if (v <= CURVE[0].volts) return 0.0f;
  if (v >= CURVE[CURVE_COUNT - 1].volts) return 100.0f;

  for (uint8_t i = 1; i < CURVE_COUNT; i++) {
    if (v <= CURVE[i].volts) {
      float span = CURVE[i].volts - CURVE[i - 1].volts;
      float frac = (v - CURVE[i - 1].volts) / span;
      return CURVE[i - 1].percent + frac * (CURVE[i].percent - CURVE[i - 1].percent);
    }
  }
  return 100.0f;
}

// ---------------- Battery voltage (averaged, calibrated by the ESP32 core) ----------------
float readBatteryVolts() {
  uint32_t sum = 0;
  for (uint8_t i = 0; i < ADC_SAMPLES; i++) {
    sum += analogReadMilliVolts(PIN_VBAT_ADC);
    delayMicroseconds(200);
  }
  float pinVolts = ((float)sum / (float)ADC_SAMPLES) / 1000.0f;
  return pinVolts * DIVIDER_RATIO * VBAT_CAL;
}

// ---------------- Charge enable control (CE: LOW = enabled) ----------------
void setCharge(bool enable) {
  if (enable == chargeEnabled) return;
  chargeEnabled = enable;
  digitalWrite(PIN_CE, enable ? LOW : HIGH);
  Serial.println(enable ? "Charging enabled" : "Charging paused (CE high)");
}

void updateChargeLimit(float vbat) {
  if (!LIMIT_CHARGE) {
    setCharge(true);
    return;
  }
  if (chargeEnabled && vbat >= CHARGE_STOP_V) {
    setCharge(false);
  } else if (!chargeEnabled && vbat <= CHARGE_RESUME_V) {
    setCharge(true);
  }
}

// ---------------- Detect charge timer fault (CHG flashes at about 2 Hz) ----------------
void sampleChg(bool chgNow) {
  if (chgNow != lastChg) {
    chgToggles++;
    lastChg = chgNow;
  }
  if (millis() - windowStart >= 2000) {
    timerFault = (chgToggles >= 6);
    chgToggles = 0;
    windowStart = millis();
  }
}

// ---------------- Protective sleep ----------------
void enterProtectiveSleep() {
  Serial.println("Battery very low and no external power. Entering deep sleep.");
  if (oledOk) {
    display.clearDisplay();
    display.setTextSize(1);
    display.setTextColor(SSD1306_WHITE);
    display.setCursor(0, 20);
    display.println("LOW BATTERY");
    display.println("Sleeping...");
    display.display();
    delay(1500);
    display.ssd1306_command(SSD1306_DISPLAYOFF);
  }
  esp_sleep_enable_timer_wakeup(SLEEP_US);
  esp_deep_sleep_start();
}

// ---------------- Status update ----------------
void updateStatus() {
  bool  usb   = (digitalRead(PIN_PGOOD) == LOW);
  bool  chg   = (digitalRead(PIN_CHG) == LOW);
  float vbat  = readBatteryVolts();
  float pct   = percentFromVoltage(vbat);

  updateChargeLimit(vbat);

  if (!usb && vbat < CUTOFF_V) {
    lowCount++;
  } else {
    lowCount = 0;
  }
  if (lowCount >= 5) {
    enterProtectiveSleep();
  }

  const char* state;
  if (timerFault)                 state = "CHARGE FAULT";
  else if (usb && chg)            state = "USB + CHARGING";
  else if (usb && !chargeEnabled) state = "USB, CHARGE HOLD";
  else if (usb)                   state = "USB, CHARGED";
  else if (vbat < LOW_BATT_WARN_V) state = "BATTERY LOW";
  else                            state = "BATTERY ONLY";

  if (oledOk) {
    display.clearDisplay();
    display.setTextSize(1);
    display.setTextColor(SSD1306_WHITE);

    display.setCursor(0, 0);
    display.println(state);

    display.setCursor(0, 16);
    display.print("Vbat: ");
    display.print(vbat, 2);
    display.println("V");

    display.setCursor(0, 28);
    display.print("Level: ~");
    display.print(pct, 0);
    display.println("%");

    display.setCursor(0, 40);
    display.print("Input: ");
    display.println(usb ? "GOOD" : "NONE");

    display.setCursor(0, 52);
    display.print("Charge: ");
    display.print(chargeEnabled ? "ENABLED" : "PAUSED");

    display.display();
  }

  Serial.printf("State=%s Vbat=%.2fV Level=~%.0f%% PG=%d CHG=%d CE_enabled=%d\n",
                state, vbat, pct, usb, chg, chargeEnabled);
}

// ---------------- Setup ----------------
void setup() {
  Serial.begin(115200);
  delay(200);

  pinMode(PIN_CE, OUTPUT);
  digitalWrite(PIN_CE, LOW);          // Charging enabled by default
  pinMode(PIN_PGOOD, INPUT);          // External 10k pull-up to 3V3
  pinMode(PIN_CHG, INPUT);            // External 10k pull-up to 3V3
  pinMode(PIN_VBAT_ADC, INPUT);
  analogSetPinAttenuation(PIN_VBAT_ADC, ADC_11db);

  Wire.begin(I2C_SDA_PIN, I2C_SCL_PIN);
  oledOk = display.begin(SSD1306_SWITCHCAPVCC, OLED_ADDR);
  if (!oledOk) {
    Serial.println("WARNING: SSD1306 not found. Continuing with Serial output only.");
  }

  lastChg = (digitalRead(PIN_CHG) == LOW);
  windowStart = millis();

  Serial.println("Power-path charger monitor ready.");
}

// ---------------- Main loop ----------------
void loop() {
  unsigned long now = millis();

  if (now - lastSample >= 50) {
    lastSample = now;
    sampleChg(digitalRead(PIN_CHG) == LOW);
  }

  if (now - lastUpdate >= 500) {
    lastUpdate = now;
    updateStatus();
  }
}

Step-By-Step Implementation Guide

Step 1: Set the Charge Current

  • Choose a charge current of about 0.5C or less for your cell. For a 2000mAh battery, 1A is the upper limit and 0.5A is gentler.
  • On the charger board, cut the trace on the 1.0A solder jumper and bridge the 0.5A jumper (or leave 1.0A for larger cells).

Step 2: Verify Battery Polarity Before Connecting

  • JST battery connectors from different sellers can have reversed wiring. Check the charger board silkscreen and use a multimeter on the battery plug.
  • If the polarity is reversed, re-pin the connector. Never assume it matches.

Step 3: Bench-Test the Power Path First

  • Connect only the battery and the charger board, with a multimeter on OUT and GND.
  • With no input power, OUT should follow the battery voltage.
  • Plug in the USB input. OUT should settle at a regulated value of no more than about 4.4V, and the charge LED should light.

Step 4: Set the Boost Module Before Connecting the ESP32

  • Feed the boost module from OUT (or a bench supply at 3.7V).
  • Turn the trimmer until the output reads exactly 5.0V. It must stay above the 4.4V OUT maximum.
  • Add the 470uF capacitor across the boost output.

Step 5: Build the Sensing Circuit

  • Make the battery divider: LIPO pin, then 100k, then the GPIO34 node, then 100k to GND, with the 100nF capacitor from the node to GND.
  • Fit the two BAT54 diodes with the striped end (cathode) toward the charger pins, and the 10k pull-ups from the GPIO side to 3V3.
  • Check the diode direction twice. A reversed diode makes the signal read incorrectly.

Step 6: Wire the ESP32 and OLED

  • Connect GPIO32 to the PGOOD diode node, GPIO33 to the CHG diode node and GPIO25 to CE.
  • Connect the OLED to 3V3, GND, GPIO21 (SDA) and GPIO22 (SCL).
  • Tie all grounds together.

Step 7: Upload the Code

  • Install the libraries and the ESP32 board package listed above.
  • Select ESP32 Dev Module and the correct COM port, then click Upload. If it stalls at "Connecting...", hold the BOOT button.
  • Open the Serial Monitor at 115200 baud.

Step 8: Calibrate the Battery Voltage

  • Measure the battery voltage with a multimeter and compare it with the Vbat value on the OLED.
  • Set VBAT_CAL to the multimeter value divided by the displayed value, then re-upload.

Step 9: Test Every Power Scenario

  • Plug in USB: the state should read USB + CHARGING while the battery is not full.
  • Unplug USB: the ESP32 must keep running and switch to BATTERY ONLY with no reset.
  • Replug USB: charging should resume while the project keeps running.
  • Optional: set LIMIT_CHARGE to true to test the charge-hold feature.

Troubleshooting and FAQs

Wiring and Hardware Problems

The battery never charges. What should I check?
Check battery polarity at the JST connector, confirm the CE pin is LOW (it is pulled low on the Adafruit board by default), and confirm the input source is within the 5V to 10V range. Also check that the CHG LED lights when input power is applied.

The CHG LED turns off. Is the battery full?
Usually yes. This charger has no separate "done" LED, so when CHG turns off the charge cycle has finished. If CHG flashes at about 2 Hz, that signals a charge timer fault. The sketch reports this as CHARGE FAULT.

The ESP32 resets when I plug or unplug the input.
The boost converter input is probably dipping. Use short, thick wires, make sure the 470uF capacitor is fitted on the boost output, and confirm the boost is set to 5.0V and rated for the ESP32's Wi-Fi current peaks.

Why not power the ESP32 directly from the OUT pin?
OUT can be as high as 4.4V and as low as the battery voltage, which is outside what a DevKit's 3.3V regulator handles well. The boost module gives a stable 5V input that the DevKit regulator handles cleanly.

PGOOD or CHG always read the same value.
Check the diode direction (stripe toward the charger pin), the 10k pull-up to 3V3, and that both signals share a ground with the ESP32.

The battery percentage jumps when I plug in the charger.
This is expected. Battery voltage rises under charge and drops under load, so the percentage is only an estimate. Use the resting voltage for a better reading.

Compilation and Upload Errors

Error: analogReadMilliVolts was not declared in this scope
Update the ESP32 board package to a recent version in the Boards Manager.

Error: Adafruit_SSD1306.h: No such file or directory
Install Adafruit SSD1306 and Adafruit GFX Library from the Library Manager, plus Adafruit BusIO if prompted.

Upload stuck on "Connecting........"
Hold the BOOT button during upload, use a data-capable USB cable, and install the CP210x or CH340 driver for your board.

Long-Tail Questions

Can I use a TP4056 instead?
A TP4056 can charge a cell, but it has no power path. When a load is attached, the charger sees the load current as battery current, so the cell may not terminate properly and is held at full voltage. For a project that runs while charging, a power-path charger is the safer design.

Can I charge and use a lithium battery at the same time?
Yes, with a power-path charger such as the BQ24074. The load runs from the input power and the remaining current charges the battery.

How do I limit a LiPo battery to 80 percent charge?
Set LIMIT_CHARGE to true. The firmware drives CE HIGH at the stop voltage, which pauses charging while the system rail stays active, and re-enables charging at the resume voltage.

Can I use a solar panel?
Yes. The Adafruit board accepts a 6V to 10V solar panel as well as USB or DC input. Check the manufacturer's solar notes for panel preparation.

Can I use this for LiFePO4 cells?
No. This charger targets 3.7V/4.2V Li-ion and LiPo cells. Use a charger designed for LiFePO4 for those chemistries.

Is it safe to leave charging overnight?
Only with a protected cell, correct charge current, and after you have tested the build while supervised. Always charge on a non-flammable surface.
